# Digital Pāḷi Dictionary

DPD is a freely-available, non-commercial project, providing high-quality Pāḷi dictionary lookup in multiple formats.

## Read the Docs
[DPD Docs website](https://digitalpalidictionary.github.io)

## How to Cite

DPD is revised every month, so please cite the version you used.

> Bodhirasa Bhikkhu. _Digital Pāḷi Dictionary_. Version _&lt;the version you used&gt;_. https://www.dpdict.net/
