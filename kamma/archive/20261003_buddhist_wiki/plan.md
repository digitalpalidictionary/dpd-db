# Plan: Wikipedia Buddhist Encyclopedia Dictionary (other-dictionaries)

Spec: `kamma/threads/20261003_wikipedia_buddhist_dict/spec.md`

## Architecture Decisions

- **Follow the existing `dictionaries/<name>/` module pattern exactly** (model: `dictionaries/nyanatiloka/nyanatiloka.py`): a `main()` that builds `list[DictEntry]` and calls `vendor.dpd_tools.goldendict_exporter.export_to_goldendict_with_pyglossary` + `vendor.dpd_tools.mdict_exporter.export_to_mdict`. No new exporter framework; vendor code unchanged.
- **Scheme placeholder at build time.** The entry builder emits internal anchors with a neutral placeholder scheme (`wiki://Title`). Two thin export wrappers substitute `bword://` (GoldenDict) and `Entry://` (MDict) just before calling the vendor exporters. This keeps the builder target-agnostic and testable.
- **Wikitext, not plain-text extracts**, is the fetch target: `prop=extracts&explaintext` strips `[[links]]`; wikitext preserves them. Parsing via `wikitextparser` (new dependency in `resources/other-dictionaries/pyproject.toml`).
- **Phase 1 fetches via API** (small volume: 200–500 articles; rate limits tolerable with backoff + resume). **Phase 2 strategy decided from Phase 1 throughput data**: if API throughput projects to an unacceptable wall-clock time, switch to dump-based fetch (`enwiki-latest-pages-articles` + `categorylinks.sql.gz`). The decision gets recorded in `tech.md` per the workflow's deviation rule.
- **Redirects** are resolved via the API redirect table; redirect titles become synonyms of the target entry. Redirect links inside wikitext normalize to the target article. *(Phase 2: redirects come from the `redirect` SQL dump via `make_redirects.py` — see 2.2.)*
- **Large fetch artifacts are gitignored** (precedent: Apte's `ap90web1.zip`); only the seed list (Phase 1) and the final article list (Phase 2) are tracked.
- **Attribution**: CC BY-SA 4.0 in `DictInfo.description`; a dedicated "About Wikipedia Buddhist Encyclopedia" entry; a per-entry footer line linking to the online article (evidence of source + share-alike compliance). Naming follows the AGENTS.md attribution rule: name the source in the bookname/description, never bury it in `author`.
