# Tipitaka Pali Reader

**Tipitaka Pali Reader** is an app for reading Pāḷi texts being developed by Ven. Paññadhaja in Myanmar, and managed by [Ven. Subhuti](https://americanmonk.org/){target="_blank"}. You can find out more information about TPR on [his website](https://americanmonk.org/tipitaka-pali-reader/){target="_blank"}.

TPR is available for all OS's and devices. Download the latest version for Windows, Mac, LInux, iOS, Android from [the releases page on GitHub](https://github.com/bksubhuti/tipitaka-pali-reader/releases){target="_blank"}

Each new version of TPR will include the latest DPD release.

To open a word in the dictionary, simply click on it and the dictionary will pop up. TPR uses the same system for recognizing inflections and sandhi as DPD, so only correct possibilities should be displayed.

![click_word](../pics/tpr/tpr_click_word_dark.png#only-dark)
![click_word](../pics/tpr/tpr_click_word_light.png#only-light)

To see detailed grammatical information, click the small arrow on the dictionary entry and more info will become visible. 

![grammar_info](../pics/tpr/tpr_open_grammar_dark.png#only-dark)
![grammar_info](../pics/tpr/tpr_open_grammar_light.png#only-light)

The DPD grammar dictionary is also included to show the possible declensions and conjugations of the word.

![dpd_grammar](../pics/tpr/tpr_grammar_info_dark.png#only-dark)
![dpd_grammar](../pics/tpr/tpr_grammar_info_light.png#only-light)


## Updates

Each new TPR release includes a recent version of DPD. To get newer DPD data, update TPR to its latest release.
