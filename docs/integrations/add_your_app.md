# Add Your App

Have you built an app or website that uses DPD? We would love to give it its own page here.

Most developers are great at building apps and not so great at telling people about them. This template is here to help. Answer the questions below and we will turn your answers into a page like the other ones in this section.

## The Easy Way

This looks like a long form, but you don't have to fill it in yourself. Get your favourite AI agent to do it for you.

Open your AI agent in your app's code folder, and paste this in:

```text
Read the template at https://digitalpalidictionary.github.io/integrations/add_your_app/
Fill in every section for this app, using the code, README, docs and website.
Write the answers into a file called add_your_app.md in this folder, keeping every heading.
Leave a section blank if you can't find the answer, and list those sections at the end.
```

If your AI agent can't open web pages, save this page and give it the file instead.

Then read what it wrote, fix anything it got wrong, and fill in the gaps. The questions about what sets your app apart, and who it is for, need your own words most of all.

## How to Send It

If you used the easy way, skip to step 3.

1. Copy the headings below into an email or a text file.
2. Write your answers under each heading. Skip anything that does not apply.
3. Make your screenshots (see [Screenshots](#screenshots) below).
4. Email everything to [digitalpalidictionary@gmail.com](mailto:digitalpalidictionary@gmail.com).

Don't worry about polish. Plain notes and bullet points are fine. We will do the editing and send you the page to check before it goes live.

## The Basics

### App Name

What is your app called? If it has a short name or nickname that people use, add that too.

### One-Line Summary

Describe your app in one sentence, as if to a friend who has never heard of it.

For example: *"A free desktop app for reading the Pāḷi Canon with a dictionary popup on every word."*

### Who Makes It

Who develops and maintains the app? A person, a group, a monastery, an organisation? Where are you based? You can stay anonymous if you prefer.

### Website

For example: `https://www.example.com`

### Docs or Help Site

For example: `https://docs.example.com`

If your help pages are part of your main website, give the link to the help page itself.

### Source Code

For example: `https://github.com/your-name/your-app`

Is the code open source? Under what licence?

### Cost

Is the app free? Is there a paid version, donations, or in-app purchases?

### Contact

How can users reach you? An email address, a contact page, a forum, a Telegram or Discord group?

### Bug Reports

Where should users report bugs or request features? For example, a GitHub issues page or a feedback form.

## About the App

### What Does It Do?

Describe what the app does in a short paragraph. What can a user do with it on their first day?

### Who Is It For?

Who will get the most out of your app? Beginners learning Pāḷi, serious students, translators, meditators, teachers, scholars?

### Main Features

List the main features, one per line. For example:

- Full Chaṭṭha Saṅgāyana Tipiṭaka
- Side-by-side Pāḷi and English
- Full-text search
- Bookmarks and notes

### Texts and Content

Which texts, translations and dictionaries does the app include, besides DPD? Where do they come from?

### Languages

Which languages does the app's interface come in? Which scripts can it show Pāḷi in (Roman, Myanmar, Sinhala, Thai, Devanagari, other)?

### Similar Apps

Which other apps or websites are similar to yours?

### What Sets It Apart?

What can your app do that the similar apps cannot? Why would someone choose yours? This is the most important question on the page, so don't be shy.

### Other Features Worth Knowing

Is there anything else in the app worth a mention, such as AI tools, audio, flashcards or chanting books? Are there any warnings users should know about these features?

## How DPD Is Used

### Which Version of DPD?

Which version of DPD does your app use? For example:

- the full DPD
- a light version (meanings and grammar only)
- the DPD grammar dictionary or deconstructor
- DPD Online, embedded or in a new window
- several of these, as user options

### Which Parts of DPD?

Which parts of DPD does your app show? For example: meanings, grammar, construction, roots, inflection tables, compound breakdowns, examples, frequency.

### Looking Up a Word

How does a user look up a word? Click, tap, hover, right-click, select text, type in a search box? What does the popup or panel show, and what buttons does it have?

### Turning DPD On

Is DPD on by default? If not, give numbered steps to turn it on. Add one screenshot for each step.

1. Open ...
2. Click ...
3. Select ...

### Dictionary Settings and Modes

Can the user change how DPD looks or works? List each option and say what it does.

### Getting the Latest DPD

DPD has a new release every month, on the Uposatha day. How does your app get the latest version?

- Automatically, when DPD releases?
- The user downloads an extension or update? Give the steps.
- With the next app update?
- Is there a beta or test version of DPD available?

### DPD in Other Languages

Does your app offer DPD in other languages, such as Russian?

## Screenshots

Screenshots sell an app better than words. Please send:

- One screenshot of the app's main screen.
- One screenshot of a DPD lookup in action.
- One screenshot for each numbered step in [Turning DPD On](#turning-dpd-on) and [Getting the Latest DPD](#getting-the-latest-dpd).

This site has a light mode and a dark mode, so please send each screenshot twice: once with your app in light mode and once in dark mode. If your app has only one mode, one copy is fine.

Name each pair like this:

- `lookup_light.png`
- `lookup_dark.png`

Tips:

- Crop to the part that matters. Don't send the whole desktop.
- Use the PNG format.
- Use a real Pāḷi text and a real word lookup, not an empty screen.
- Say in a word or two what each screenshot shows.
